<refract-logo>

A drop-in WebGL2 render of a logo as spectral glass or chrome. Hover to steer the light, drag to spin. One script, no dependencies.

<script src="refract-logo.js"></script>
<refract-logo sample="hermes" background="#0b0b0c" style="height:560px"></refract-logo>

On a light page

Set background to the page colour: Refract draws it as its own backdrop (so the glass still has something to refract) and matches it at the edges, so the render melts into the page. Light colours pick the light theme automatically.

<refract-logo sample="x" background="#f3f1ed"></refract-logo>

Card

Chrome, studio light, matched to the card colour.

<refract-logo sample="vercel" material="chrome" light="studio"
  background="#16171a" thickness="60" roundness="40"></refract-logo>

Transparent: true alpha over any page. Flatter, because the glass can't refract the page behind it (it refracts the theme colour instead; use theme="light" on light pages).

<refract-logo sample="vercel" transparent></refract-logo>

Non-interactive: idle animation only, never captures the pointer or blocks scrolling.

<refract-logo text="Prism" interactive="false"
  background="#3b4658"></refract-logo>

React

import { RefractLogo } from './refract-logo-react.js';

<RefractLogo sample="hermes" material="glass" background="#0b0b0c"
  style={{ height: 480 }} onReady={() => console.log('ready')} />
